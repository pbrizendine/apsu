APSU uses browser storage as well as the technologies commonly called cookies. This build does not include advertising or analytics tracking.

Essential storage

Supabase stores the authentication session in browser local storage so you stay signed in when moving between pages or returning later. Logging out removes the application session. APSU also stores your storage choice, a short-lived exit notice, and an under-age registration flag for the current browser session. Hosting providers may use security or network mechanisms to deliver the site.

Solo saves

Solo worlds you create or import are saved in IndexedDB on this browser and website address. They persist independently of optional appearance preferences. Export a backup before clearing site data. Signing in does not upload these saves.

Appearance preferences

Message read markers last for this tab. APSU keeps your selected theme and panel arrangement in session storage for the current tab. With “Remember preferences,” APSU also saves them on this device between visits. “Essential only” keeps those choices in memory for the current page instead. Both options leave the site usable.

Change your choice

Use or the same control in the footer. Choosing Essential only removes APSU’s saved appearance preferences. It does not sign you out. Browser settings can remove all site storage, which will sign you out and reset preferences.

Storage lifetime

The storage choice and optional preferences remain until you change them or clear site data. Authentication tokens follow the session and refresh rules of the authentication service. Session notices and the age-screen flag end with the browser session. These settings are specific to the browser you are using.
